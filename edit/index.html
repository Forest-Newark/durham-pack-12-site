Three steps to publish

  1. Make your changes in this form. Nothing goes live yet.
  2. Download your update. This saves a file named site.json.
  3. Upload it to GitHub’s content folder, replacing the existing site.json. Commit the change. GitHub checks and publishes the website.

You need permission to update the GitHub repository. This form does not publish directly or ask for a password.
