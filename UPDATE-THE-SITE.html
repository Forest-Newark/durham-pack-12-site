How to update the website

Open the website editor →

  1. Change the meeting details, contacts, events, or resources in the form.
  2. Choose Download your update. Keep its filename exactly site.json.
  3. Choose Open GitHub upload. Upload that file into the repository’s content folder, replacing content/site.json.
  4. Commit your change. Wait for the Check and deploy Pack 12 Pages workflow to finish, then refresh the website.

Adding a document

Upload your PDF to the uploads folder first. Set the resource link to ./uploads/your-file.pdf in the editor, then download and publish the content update.

Saving a draft

Saving on this device keeps your changes in this browser. It does not publish them. Start from the current website for each new update so you do not replace another volunteer’s changes with an older snapshot.

Who can publish?

You need permission to update the GitHub repository. The editor does not ask for passwords or access tokens. Only a GitHub commit changes the published website.
